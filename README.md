# 준스키타운 렌탈샵 (ski-rent-shop)

스키 렌탈샵 "준스키타운" 관리자 페이지 구현입니다.
[Claude Design](https://claude.ai/design/p/62b09341-9bfb-4960-9165-b86bec0aba5b?file=Admin.dc.html)에서 제작한 `Admin.dc.html` 화면을 바닐라 HTML/CSS/JS로 구현했습니다.

## 페이지

| 파일 | 설명 |
|---|---|
| `index.html` | 진입 페이지 (관리자 페이지로 이동) |
| `admin-login.html` | 관리자 로그인 |
| `admin.html` + `admin.js` | 관리자 페이지 (렌탈 품목 · 할인 설정 · 공지사항 · 문의 답변 관리) |

## 주요 기능

- **렌탈 품목 관리** — 리프트권 · 장비 · 의류 · 안전장비 탭별로 품목 추가/수정/삭제, 기본값 되돌리기
- **할인 설정** — 기본 할인 / 제휴업체 할인 (퍼센트·정액), 제휴 키워드 관리
- **공지사항 관리** — 공지 작성/수정/삭제
- **문의 답변 관리** — 문의 펼쳐보기, 답변 등록 시 상태 자동 변경(답변대기 → 답변완료)
- 모든 변경사항은 브라우저 `localStorage`에 자동 저장

## 실행

정적 사이트라 별도 빌드 없이 바로 열 수 있습니다.

```bash
python3 -m http.server 8080
# http://localhost:8080 접속
```

> 로그인 화면은 데모용으로, 아이디/비밀번호 입력 후 로그인하면 관리자 페이지로 이동합니다.
